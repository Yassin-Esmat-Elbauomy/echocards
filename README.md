# EchoCards

A flashcard study web app built with HTML, CSS, and JavaScript. Runs offline in the browser using IndexedDB and reads cards out loud with Web Speech Synthesis.



## Features & controls
- Create decks and add, edit, or delete flashcards (saved in `indexedDB`)
- Built with custom Web Components and Shadow DOM (`<deck-list>`, `<flash-card>`, `<card-editor>`)
- Text-to-speech controls for mute, speech speed, voice selection, and auto-speak
- Keyboard shortcuts in Study Mode: `Space` to flip, `S` to speak, `ArrowLeft` / `ArrowRight` for prev/next card


I built this for the Grandma program in Hackclub so I hope you like it!
